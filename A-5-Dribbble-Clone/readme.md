# Dribbble Clone 🎨

A fully responsive Dribbble-inspired landing page built using HTML5 and CSS3.  
The project focuses on modern UI development, responsive layouts, hover interactions, and clean frontend structure.

## 🌐 Live Demo

https://dribbble-clone-sudhanshu.pages.dev/

## 🚀 Features

- Responsive Design
- CSS Grid & Flexbox
- Interactive Hover Effects
- Search Bar UI
- Infinite Logo Animation
- Mobile Friendly Layout

## 🛠️ Tech Stack

- HTML5
- CSS3
- Remix Icons

## 📚 Skills Demonstrated

- Responsive Web Design
- Flexbox & CSS Grid
- Media Queries
- Modern UI Development
- CSS Animations
